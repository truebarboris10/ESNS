Extended+ Storage Naming System (ESNS)
The Extended+ Storage Naming System (ESNS) is a proposed system for naming and defining units of digital information and storage.
ESNS includes standard information units and custom units, including fractional units, decimal units, binary units, and extended custom units.

Project status
ESNS is a proposed naming system. Its specification is being prepared for public release and review.
Publication does not by itself constitute recognition as an international standard.
Definitions
The names, values, and conversion rules of ESNS units are documented in the specification and its associated catalog.
